# Features

## Program Planning
- Build personalized mesocycle-based training plans.
- Select and sequence exercises for each session.
- Mark specific sets with advanced training techniques.

## Workout Logging
- Log each set and rep per exercise in a workout.
- Add/edit notes per workout or exercise.

## Progress Dashboard
- Visualize progress with graphs (weekly sets per muscle group).
- View recent and past workout summaries.
- Weekly/monthly filters for workout history.

## User Account Management
- Secure registration and login.
- Edit profile details.
- Access all historical logged data.

## (Planned / Future)
- Advanced analytics and recommendations.
- Integration with external fitness apps.
